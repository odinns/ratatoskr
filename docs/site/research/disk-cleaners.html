Disk cleaner comparison.

This page is not linked from the public site. It is a feature smell test for Ratatoskr, not marketing copy.

Short read.

Ratatoskr’s gap is not “find big files”. Plenty of tools do that. The useful gap is safe, inspectable, local, rule-backed cleanup for developer/project waste with agent-readable reports.

Ideas worth stealing.

Preview-first workflow

Scan, review, then delete. Ratatoskr already wants this. Keep it sacred.

Rule explanations

Show owner, deletion cost, exclusions, consequence, and default-cleanability beside each candidate.

Large-file awareness

Show big files without deletion pressure. Unknown large files stay report-only.

Agent-readable export

Structured JSON for judgment is a real differentiator. Make it boring, complete, and private by default.

Trash first

Recovery matters. Permanent delete should need a separate, explicit decision.

Developer waste profiles

Laravel, Node, Composer, coverage, Playwright, framework caches. Consumer cleaners mostly miss the useful teeth.

Target mode

“I need 17 GB.” Rank safe and cautious candidates until the target is met. Better than a giant list.

Landing page lessons.

The useful lesson is not feature count. It is how each tool earns trust, explains deletion, or quietly reveals what Ratatoskr should refuse to become.

BleachBit

Preview is the product. Keep saying that every file is shown before deletion, and make custom rules inspectable instead of magical.

Czkawka

Core-library plus CLI is smart. Ratatoskr should keep scan logic separate from presentation so reports, skills, and future commands share the same judgment.

GrandPerspective

Filters, saved scans, and export matter. Ratatoskr does not need a treemap, but it does need repeatable reports users can compare after cleanup.

ClearDisk

The strongest direct signal: developer cache catalog, project artifact scanning, risk levels, cache descriptions, and trash-first cleanup. Skip the menu-bar monitor.

Sweepo

Simple two-step framing works: scan, review, clean. Downloads auto-organization is useful for consumers, but it is outside Ratatoskr's safety model.

OmniDiskSweeper

Largest-first browsing is still valuable. Ratatoskr should rank candidates by reclaimable size and make "open/reveal this path" easy in text output.

CCleaner

Quick Scan is a good name for guided defaults. Automatic browser cleanup, photo analysis, and startup management are not Ratatoskr's lane.

Nektony

Separate utilities make the scope understandable: cleaner, uninstaller, duplicate finder, disk analyzer. Ratatoskr should stay one sharp tool, not a suite.

DaisyDisk

Best critique of cleaners: caches come back. Ratatoskr should distinguish durable wins from temporary cache relief in reports.

CleanMyMac

Trust badges and big numbers sell confidence, but the feature soup gets blurry. Ratatoskr's advantage is narrower scope and stronger explanations.

AVG TuneUp

Automatic cleanup is a strong promise and a weak safety model. Ratatoskr should make automation explicit, reversible, and boringly limited.

Norton

The landing page buries Utilities Ultimate inside bundle noise, and the utility is Windows-only there. Clarity beats brand weight.

Avast Cleanup

Photo cleanup dominates the pitch: duplicates, similar photos, bad photos. Ratatoskr should name this as a non-goal instead of drifting into personal-file judgment.
