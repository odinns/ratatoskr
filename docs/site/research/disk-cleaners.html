Disk cleaner comparison.

This page is not linked from the public site. It is a feature smell test for Ratatoskr, not marketing copy.

Short read.

Ratatoskr’s gap is not “find big files”. Plenty of tools do that. The useful gap is safe, inspectable, local, rule-backed cleanup for developer/project waste with agent-readable reports.

Legend: green check means the feature is available free. Red X means the feature is paid. Empty means not supported or not clearly advertised. Grey slash means Ratatoskr should not do it.

Ideas worth stealing.

Preview-first workflow

Scan, review, then delete. Ratatoskr already wants this. Keep it sacred.

Rule explanations

Show owner, deletion cost, exclusions, consequence, and default-cleanability beside each candidate.

Large-file awareness

Show big files without deletion pressure. Unknown large files stay report-only.

Agent-readable export

Structured JSON for judgment is a real differentiator. Make it boring, complete, and private by default.

Trash first

Recovery matters. Permanent delete should need a separate, explicit decision.

Developer waste profiles

Laravel, Node, Composer, coverage, Playwright, framework caches. Consumer cleaners mostly miss the useful teeth.

Target mode

“I need 17 GB.” Rank safe and cautious candidates until the target is met. Better than a giant list.
